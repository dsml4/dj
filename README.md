# Dagster+Jupyter (DJ)

The Python library enables execution of notebooks in two contexts:
1. Dagster(**D**) op in the pipeline
2. standalone notebook in Jupyter (**J**).

Execution in the J context is useful for notebooks development in the interactive Jupyter environment by Data Scientists, and execution in the D context is needed to build an environment for running reproducible experiments.
